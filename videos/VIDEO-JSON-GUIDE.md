# 📄 دليل `video.json` — دماغ كل فيديو

كل فيديو في القناة بيتحكمه ملف واحد: `videos/<id>/video.json`.
**كل موظف يكتب قسمه هو بس**، وبعدين يسلّم تقرير للمستخدم ويعاين — مينفعش الموظف
اللي بعده يبدأ قبل الموافقة.

---

## 🏗️ بنية الملف

| القسم | بيwriteه مين | الوصف |
|---|---|---|
| `meta` | مدير المحتوى | الحالة، صاحب الملف الحالي، سجل التسليمات |
| `research` | الباحث | الأسئلة، الحقائق + مصادرها، المرئيات المقترحة |
| `hook` | كاتب السكريبت | الهوك (أول 30 ثانية) |
| `intro` | كاتب السكريبت | الانترو: لوجو + صوت مميز |
| `scenes[]` | كاتب السكريبت | المشاهد: تعليق صوتي + مرئي + انتقال |
| `outro` | كاتب السكريبت | الخاتمة + أسئلة تفاعلية |
| `audio` | التعليق الصوتي + الميكسر | صوت، موسيقى، مؤثرات |
| `seo` | مدير السيو | عنوان، وصف، تاجات |
| `thumbnail` | مصمم الثمبنيل | 3 أفكار + المختار |
| `publish` | منسق النشر | الموعد + Checklist |
| `review` | مدقق الحقائق + محرر اللسانيات + المستخدم | بوابات الموافقة |

## 🎬 بنية المشهد (scene)

```jsonc
{
  "id": 3,                          // رقم تسلسلي
  "section": "المصدر",              // القسم اللي ينتمي له (اختياري للتجميع)
  "narration": "المطر بيمشي على الصخور...",  // التعليق الصوتي — مرتبط بالمرئي 100%
  "duration_sec": 8,                // ⛔ أقصى حاجة 10 ثوانٍ
  "visual": {
    "type": "stock",                // stock | image | logo | generated
    "source": "pexels",             // pexels | pixabay | unsplash | google | wikipedia
    "url": "https://...",           // لينك مباشر
    "local_file": "",               // أو مسار ملف محلي
    "rights": "Pexels License",     // ⛔ إلزامي — حقوق الاستخدام
    "camera_move": "zoom-in"        // إلزامي للصور الثابتة (google/wikipedia)
  },
  "transition_in": "fade",          // ⛔ إلزامي: fade | cut | zoom | swipe | slide
  "sfx": "whoosh",                  // مؤثر صوتي (اختياري)
  "music_cue": "build-up"           // إشارة للموسيقى (اختياري)
}
```

## ⛔⛔ الأوامر العسكرية (يتحقق منها `validate_video.py`)

1. **مدة المشهد ما تزيدش عن 10 ثوانٍ.**
2. **كل مشهد لازم:** تعليق صوتي + مرئي (بمصدر ولينك) + حقوق استخدام + انتقال.
3. **ارتباط كامل:** الفيديو ما ينشرش إلا و `voiceover.synced = true`.
4. **حقوق الاستخدام:** كل أصل مسجّل بـ `rights` (Pexels License / Pixabay License /
   Unsplash License / CC / Google Images).
5. **مصادر المرئيات:** pexels / pixabay / unsplash — ومسموح صور من Google أو Wikipedia
   **بشرط إضافة حركة كاميرا** (zoom-in / zoom-out / pan…).
6. **ممنوع تكرار نفس الصورة/الفيديو** أكتر من مرة في الفيديو.
7. **انتقال إلزامي بين كل مشهدين.**
8. **الموسيقى من YouTube Audio Library بس.**
9. **كل موظف يكتب قسمه ويسلّم تقرير للمستخدم** — اللي بعده ما يبدأش قبل الموافقة.

## 🔁 سلسلة التسليم

```
researcher → fact-checker → scriptwriter → language-editor → seo-manager
→ thumbnail-designer → voiceover-artist → audio-mixer → publisher → المستخدم
```

كل مرحلة: الموظف يكتب قسمه في `video.json` + يضيف سطر في `meta.history`
(المرحلة، اسمه، التاريخ، ملخص التقرير) — وبعد موافقة المستخدم، اللي بعده يبدأ.

## ✅ التحقق

```bash
python3 scripts/validate_video.py videos/<folder>/video.json
```
