# 🎬 مساحة شغل الفيديوهات

كل فيديو له فولدر بالشكل: `YYYY-MM-DD-عنوان-الفيديو/`

## دورة حياة الفيديو

| الملف | المسؤول | المرحلة |
|---|---|---|
| `01-idea.md` | الباحث | الفكرة والتقييم |
| `02-research.md` | الباحث + مدقق الحقائق | البحث والتحقق |
| `03-script.md` | كاتب السكريبت | السكريبت + موافقة CEO |
| `04-review.md` | محرر اللسانيات | المراجعة اللغوية |
| `05-seo.md` | مدير السيو | العنوان والوصف والتاجات |
| `06-thumbnail.md` | مصمم الثمبنيل | أفكار الثمبنيل |
| `07-publish.md` | منسق النشر | النشر والمتابعة |

## إزاي تبدأ فيديو جديد؟

```bash
./scripts/new_video.sh "ليه البحر مالح؟"
```
