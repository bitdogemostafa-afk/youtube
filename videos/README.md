# 🎬 مساحة شغل الفيديوهات — منظومة `video.json`

كل فيديو فولدر بالشكل: `YYYY-MM-DD-عنوان-الفيديو/` جواه **ملف واحد** هو `video.json`.

## إزاي تبدأ فيديو جديد؟

```bash
./scripts/new_video.sh "ليه البحر مالح؟"
```

## دورة حياة الفيديو (كل مرحلة = قسم في video.json)

| المرحلة | المسؤول | القسم في الملف |
|---|---|---|
| البحث | الباحث | `research` |
| التحقق | مدقق الحقائق | `review.fact_check` |
| السكريبت | كاتب السكريبت | `hook` + `scenes[]` + `outro` |
| اللغة | محرر اللسانيات | `review.language` |
| السيو | مدير السيو | `seo` |
| الثمبنيل | مصمم الثمبنيل | `thumbnail` |
| التعليق الصوتي | فنان التعليق | `audio.voiceover` |
| الميكس | ميكسر الصوت | `audio.music / sfx / mixer_notes` |
| الجدولة | منسق النشر | `publish` |
| الموافقة | المستخدم | `review.user_approval` |

## القواعد المختصرة

- ⛔ المشهد ≤ 10 ثوانٍ
- ⛔ كل مشهد: تعليق صوتي + مرئي بحقوق استخدام + انتقال
- ⛔ صور Google/Wikipedia لازم حركة كاميرا
- ⛔ ممنوع تكرار نفس الصورة
- ⛔ الموسيقى من YouTube Audio Library
- ⛔ التسليم بالتسلسل + تقرير للمستخدم بعد كل مرحلة

📄 التفاصيل الكاملة: [`VIDEO-JSON-GUIDE.md`](VIDEO-JSON-GUIDE.md)

## مثال

شوف فولدر `EXAMPLE-ليه-البحر-مالح/video.json` — فيديو كامل مكتوب بكل الأقسام.
