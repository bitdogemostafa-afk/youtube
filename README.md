# 📺 YouTube Channel Production System

خط إنتاج آلي لقناة علوم عربية (باللهجة المصرية) بدون وجه — **فولدرين بس** + ملفات الإنتاج في الروت.

## Structure

| Path | What |
|---|---|
| `brand/` | ملفاتك: اللوجو، الانترو، الموسيقى، المؤثرات، فيديوهات حقيقية (التفاصيل في `brand/README.md`) |
| `الموظفين/` | موظف = ملف أوامر (بالإنجليزي) — خط الإنتاج بيمشي بالترتيب |
| `video.json` | خطة الفيديو الحالي (مصدر الحقيقة لـ `build_video.py`) |
| `build_video.py` | أداة التجميع: `python3 build_video.py` → `final.mp4` |
| `make_music.py` | مولّد موسيقى خليجية + مؤثرات **مؤقتة** (لما مفيش ملفات حقيقية) |
| `final.mp4` | الناتج النهائي |
| `.build/` | ملفات بناء مؤقتة (مش بتترفع على git) |

## Pipeline (الموظفين بالترتيب)

1. `researcher` — البحث + دراسة المنافسين + الهوكات
2. `fact-checker` — التحقق من كل معلومة بمصادرها
3. `scriptwriter` — السكريبت الدرامي (هوك + حلقات مفتوحة + pattern interrupts)
4. `language-editor` — صقل العربي المصري
5. `voiceover-artist` — التعليق الصوتي (كل مشهد 10 ثوانٍ)
6. `thumbnail-designer` — الثامبنيل (برومبتات إنجليزي + النص العربي بـ drawtext)
7. `seo-manager` — العنوان والوصف والوسوم
8. `audio-mixer` — الموسيقى الخليجية + المؤثرات + الدَك
9. `video-editor` — التجميع بـ `build_video.py` + المراجعة
10. `publisher` — بوابة الموافقة (مافيش نشر بدون موافقتك)
11. `data-analyst` — تحليل الأداء بعد النشر

## Hard rules (مفروضة في الكود مش في الكلام)

1. كل مشهد **10.0 ثانية بالظبط** (`meta.scene_duration`).
2. كل البرومبتات **بالإنجليزي** (العربي بيكسّر الصور).
3. انتقالات **xfade حقيقية** (0.5s) — مفيش قُصّ.
4. التعليق الصوتي درامي: أول كلمة في نص ثانية + حلقة مفتوخة كل مشهد + pattern interrupt كل 60-90ث.
5. موسيقى مناسبة للمزاج (cinematic/mystery) + whoosh على كل انتقال، والصوت فوق، loudness ‎-14 LUFS.
6. كل موظف يبحث ويقارن شغله بالقنوات المرجعية قبل ما يسلّم.
7. مفيش نشر بدون موافقة صريحة.

## إزاي تنتج فيديو

1. قول للمنتج (الـ agent) الموضوع + المدة.
2. الموظفين 1-8 يشتغلوا → `video.json` + مرئيات `.build/scenes/` + صوت `.build/audio/`.
3. `python3 build_video.py` → `final.mp4`
4. تراجع الفيديو → `publisher` ينشر.
