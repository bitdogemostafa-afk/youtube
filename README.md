# 🏢 شركة إدارة قناة «طب ليه؟»

> **قناة يوتيوب** متخصصة في **الغرائب والأسئلة** — لغة عربية فصحى — جمهور خليجي.
> جدول النشر: **فيديوهان كل أسبوع** (الثلاثاء والجمعة 7:00 مساءً بتوقيت السعودية).

## 🗂️ هيكل الشركة

| المجلد | فيه إيه |
|---|---|
| `channel/` | هوية القناة، الجمهور، نبرة الصوت، أعمدة المحتوى |
| `employees/` | الموظفون — كل ملف = موظف بدوره ومسؤولياته وقسمه في `video.json` |
| `workflow.md` | سير العمل من الفكرة لحد النشر |
| `scripts/` | أدوات: ذاكرة الفريق + فيديو جديد + التحقق من القواعد |
| `videos/` | مساحة شغل الفيديوهات — كل فيديو ملف `video.json` |
| `assets/` | اللوجو والكوفر ونماذج الصوت |
| `context/` | ملف الذاكرة الموحد — يتولد تلقائياً |

## 👥 الهيكل الإداري (13 موظف)

```
المستخدم (صاحب القناة — يعاين كل مرحلة)
├── الرئيس التنفيذي (CEO) — المراجعة النهائية
├── مدير المحتوى — خطة الشهر وتوزيع المهام
│   ├── الباحث — الأفكار والمصادر والمرئيات
│   ├── كاتب السكريبت — الهوك والمشاهد والخاتمة
│   ├── مدير السيو — العناوين والأوصاف والتاجات
│   ├── مصمم الثمبنيل — 3 أفكار لكل فيديو
│   └── منسق النشر — الجدولة والـ Checklist
├── مدقق الحقائق — كل معلومة بمصدرين
├── محرر اللسانيات — الفصحى والأسلوب
├── فنان التعليق الصوتي — مقطع صوتي لكل مشهد
├── ميكسر الصوت — الموسيقى والمؤثرات
├── محلل البيانات — الأرقام والتوصيات
└── مدير المجتمع — التعليقات والأفكار الجديدة
```

## 🎬 إزاي الفيديو يتبنى؟ (منظومة video.json)

كل فيديو ملف `video.json` — **كل موظف يكتب قسمه هو بس ويسلّم تقرير للمستخدم
ويعاين**، وبعد الموافقة اللي بعده يبدأ:

```
researcher → fact-checker → scriptwriter → language-editor → seo-manager
→ thumbnail-designer → voiceover-artist → audio-mixer → publisher → المستخدم → النشر
```

⛔ القواعد: المشهد ≤ 10 ثوانٍ • كل مشهد له تعليق صوتي + مرئي بحقوق استخدام + انتقال •
صور Google/Wikipedia بحركة كاميرا • ممنوع تكرار الصورة • موسيقى YouTube Audio Library

📄 التفاصيل: [`videos/VIDEO-JSON-GUIDE.md`](videos/VIDEO-JSON-GUIDE.md)

## 🚀 إزاي تشغّل الشركة

1. **ابنِ الذاكرة:**
   ```bash
   python3 scripts/build_context.py
   ```
   → بيلم كل ملفات `channel/` و `employees/` في `context/team-context.md`.

2. **شغّل الفريق:** افتح `context/team-context.md` مع أي AI agent وقوله:
   > «إنت فريق إدارة قناة طب ليه؟، اشتغل بالمحتوى ده.»

3. **ابدأ فيديو جديد:**
   ```bash
   ./scripts/new_video.sh "ليه البحر مالح؟"
   ```

4. **تحقق قبل أي تسليم:**
   ```bash
   python3 scripts/validate_video.py videos/<folder>/video.json
   ```

## 📜 القواعد الذهبية

1. مفيش سكريبت بدون بحث متحقَّق منه.
2. مفيش نشر بدون موافقة المستخدم.
3. كل معلومة لازم مصدرها مكتوب في ملف البحث.
4. أي سؤال من تعليقات الجمهور يروح للباحث كفكرة جديدة.
